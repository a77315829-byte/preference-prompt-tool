실제 생성된 프롬프트의 선호 부분

아래 선호는 사용자가 여러 코드 예시를 직접 비교하며 고른 결과에서 추정한 것이다.
- 코드 구성: 컴포넌트와 스타일 또는 상태 로직을 역할별 파일로 분리하라. 필요 없는 하위 컴포넌트와 타입 전용 파일을 억지로 만들지 말고, 각 파일의 이름과 전체 코드를 명확히 제시하라.
- 스타일 관리: 색상, 간격, 글꼴 같은 디자인 값은 theme 또는 디자인 토큰으로 모아서 관리하라. 컴포넌트에서는 해당 값을 참조하여 전체 디자인을 쉽게 수정할 수 있게 하라.
- 타입 작성: Props, 함수 매개변수, 반환값, 상태와 주요 데이터 구조의 타입을 꼼꼼하게 명시하라.
다른 기능에도 적용해 보기
FAQ 질문 3개와 답변을 표시하는 React 컴포넌트. 처음에는 답변이 모두 닫혀 있고, 질문 버튼을 누르면 해당 답변만 열고 다시 누르면 닫습니다. 여러 답변을 동시에 열 수 있습니다.

전체 프롬프트는 함께 저장한 personalized-prompt.txt에서 확인할 수 있습니다. 프롬프트 개인화이며, AI 모델 자체를 학습시키는 과정은 아닙니다.

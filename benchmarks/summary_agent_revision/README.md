## 수정 내용

새 `summarization_grounded` 지침은 사실 관계를 표현 선호보다 우선하고, 작성 전에 핵심 사건,
주요 결과/목적, 중요한 수치·단위·기간, 주장 주체·조건·불확실성을 확인하도록 한다.
정한 분량 안에서 장식적 도입·주변 배경·반복을 먼저 줄이고, 발췌할 때 지시 대상이 불분명한
문장 대신 문맥이 명확한 원문 문장을 선택하도록 한다. 제출 전 누락·추가·주장 주체 변경을
대조하되 점검 과정은 출력하지 않는다. 지침 보완이며 내용 누락을 자동으로 방지한다는 보장은 아니다.

원문 표현을 많이 쓰는 `high`는 75% 상한을 제거했다. 완전 발췌는 bigram 겹침만으로 통과시키지
않고 원문의 완전 문장과 대조한다. 공백과 맨 앞의 지정 매체 태그 생략만 허용하며
수치·부정어·문장부호·주장 주체 변경과 태그 추가/교체는 거절한다. 표현 겹침은 여전히 참고 지표이며
의미나 사실성 점수가 아니다. 문장 분리는 보수적 휴리스틱이며 독립 내용 검토를 대신하지 않는다.

기존 `summarization.yaml`, 한국어 원본, 기존 검사와 연구 결과는 보존했다.
새 기본 요약 세션은 새 도메인을 사용하며, 코딩 기능과 선택 횟수 규칙은 바꾸지 않았다.
이미 저장한 프롬프트 본문을 일괄 갱신하지 않는다.

## 공정한 비교와 한계

- 같은 9개 원문·목표 설정을 세 조건에 주었다. 수동/수정 전 지침은 이전 파일럿에서 보존한
  문자열을 그대로 사용한다. 수정 후는 실제 새 YAML과 내보내기 함수로 만든다.
- 길이 3종 × 표현 3종의 9조합을 배정했다. 한 조합당 문서 하나이므로 세부 조합의 성능을 일반화하지 않는다.
- 프롬프트 개발 에이전트는 새 평가 원문을 읽지 않았다. 생성 전에 별도 에이전트가 원문에서
  핵심 명제 3개씩을 정하고 정확한 근거 인용을 검증했다. MACSum 참고 요약에도 오류가 있어
  원문을 최종 근거로 사용한다. 명제는 사람 정답 라벨이 아닌 AI 주석이다.
- 생성 에이전트 3개는 부모 이력 없이 같은 상속 모델/추론 설정으로 조건 하나씩 처리한다.
  조건 내 9개가 같은 대화에 들어가므로 27회 독립 모델 실험은 아니다. 파일 접근 제한은 지시 기반이다.
- 독립 검토자 2개는 조건명·프롬프트·자동 점수 없이 익명 결과와 원문·고정 명제만 읽는다.
  조건 준수, 핵심 명제 보존, 요약 전체의 사실 문제를 분리한다. 모든 근거 인용을 코드로 검증한다.
- 이전 실험과 달리 발췌의 지정 출처 접두어 생략을 허용하고, 명제는 부수적 세부를 묶지 않도록
  더 작게 정의했다. **이전 21/27과 이번 수치를 직접 비교하지 않는다.** 새 원문에서 세 조건을 같은 기준으로 비교한다.
- 새 원문은 직전 파일럿과 겹치지 않는다는 뜻이다. 공개 데이터의 사전학습 포함 여부나 과거 프로젝트
  전체에서 한 번도 보지 않았다는 것을 보장하지 않는다. 한국어 의미 품질·사람의 선호·시간 절감·사용 의향은 미측정이다.
- 코드/지침/평가/원문을 생성 전에 해시로 고정했다. 첫 결과를 보고 지침을 재수정하거나 더 좋은 결과를 재생성하지 않는다.

## GEPA에 대한 판단

실패 사례를 바탕으로 후보 지침을 제안·평가하는 GEPA는 후속 실험에 적합하다.
그러나 현재 `service.optimize`의 평가 함수는 길이·표현 등의 축 점수이고 내용 보존 통과 조건이 없다.
예시 문서가 학습과 검증에 중복되어 현재 서비스 점수를 독립 최종 평가로 보고할 수도 없다.
이번 작업에서는 GEPA의 외부 모델 경로를 실행하지 않았다.

다음 적용에서는 문서 단위로 **학습 / 후보 선택 / 최종 평가**를 분리하고, 원문 근거가 있는
누락·왜곡 피드백을 전달해야 한다. 사실 보존 규칙은 고정하고 후보가 이를 훼손하면 채택하지 않는다.
검증되지 않은 LLM 판정을 완벽한 사실 판별기로 취급하지 않으며, 판단이 불확실하면 별도로 기록한다.
후보 선택에 쓰지 않은 자료와 독립 지표로 확인하고 개선이 없으면 원본을 유지한다.

설치된 GEPA는 모델 호출 함수를 받을 수 있어 로컬 모델 연결은 가능하지만, Codex 보조 에이전트를
그 함수에 연결하는 구현은 현재 없다. 당장 보조 에이전트로 가능한 실패 분석→후보 제안→독립 검증은
**제한된 성찰 실험**이며 실제 GEPA 엔진 실행과 구분해야 한다. 이 실행의 테스트 원문을 나중에
개선에 사용한다면 다시 최종 검증 자료라고 부르지 않는다.

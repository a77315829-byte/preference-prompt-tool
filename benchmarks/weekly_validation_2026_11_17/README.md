# 2026-11-17 주간 최종 출력 비교

**강한 수동 지침과 현재 제품 지침은 이 작은 파일럿에서 같은 조건 준수 결과를 보였다. 제품의 수동 대비 우위는 확인하지 못했다.** 새 MACSum 영어 원문 6개와 새 React 합성 과제 8개에서 방식별 첫 응답 14개, 총 28개를 보존했다. 유료 모델 API·GEPA·새 의존성은 사용하지 않았다. Codex 보조 에이전트 사용량은 소비된다.

## 비교 범위

| 대상 | 수동 | 제품 |
|---|---|---|
| 영어 요약 | 생성 전에 작성한 강한 정확성·보존·표현·분량 지침 | `summary_contracts_v2.prepare_summary_contract()`의 실제 영어 `task_requests` |
| React 코드 스타일 | 세 조건을 명확히 적은 수동 지침 | `domains/coding/v2.yaml`을 읽은 `build_final_prompt(..., language='en')`의 반환문 |

원문·공개 기능 계약·확정된 조건·선택한 보존 문장·충돌 처리 정책은 양쪽에 같게 제공했다. 제품 문장은 수정 없이 썼다. 이미 목표 조건을 정했다고 가정한 출력 전달 검증이며, 실제 사람의 선호 추정·선택 UI·설정 노력·수정 시간·채택 의향의 검증이 아니다. 제품 문장에 있는 ‘예시에서 추정했다’는 표현도 실제 사용자 연구의 근거로 사용하지 않는다. 수동 지침은 조사자가 썼으며 모집된 사용자가 작성한 결과가 아니다.

React v2의 역할별 분리와 inferred 예외를 직접 확인한다. 스타일 파일만 의미 있게 분리해도 `separated`이며, 빈 배열·null·유니언·공개 Props·필요한 CSS 타입은 `inferred`와 양립한다. 이전 연구처럼 이 예외를 공통 계약에 별도로 덧붙여 제품의 짧은 문장을 보완하지 않았다. 동일한 선택 의미는 강한 수동 지침에도 명시했다. 개별 문구 변경의 인과 효과를 분리한 실험은 아니다.

## 절차와 검증

입력·원문·과제·판정 기준·실행기를 첫 응답 생성 전에 SHA-256으로 [고정](frozen.json)했다. 새 동작 실행기는 정답 8개가 타입·40/40 동작을 통과하고, 타입은 맞지만 동작이 틀린 변이 8개를 모두 검출한 뒤 고정했다. 준비 중 VM 간 배열의 prototype 차이로 정답의 콜백 배열 비교 6개가 오탐한 것을 발견해 배열 복사로 보완했다. [초기 실패](controls_initial_results.json)와 [최종 대조](controls_results.json)를 모두 남겼으며 생성 후에는 테스트를 바꾸지 않았다.

서로 독립된 `fork_turns=none` 생성자 두 명은 자기 방식의 입력만 받고 같은 순서로 14개를 작성했다. 테스트·다른 방식·이전 출력·사실 표를 보지 않았으며 코드를 실행하지 않았다. 첫 응답을 [봉인](generation_seal.json)한 뒤 전체 24개 TSX/TS/CSS 파일을 그대로 추출하고, 직접 코드 검토와 기존 AST 안전 검사를 거쳐 실행했다. 빠진 코드를 보충하거나 답변을 고치거나 재생성하지 않았다.

- **타입:** 설치된 TypeScript 5.9.3 strict, React 공개 `Component`·`Props` 양방향 호환성, 명시적 any·억제문을 확인했다.
- **동작:** React/ReactDOM 19.3.0·JSDOM 20.0.3에서 렌더링·입력·클릭·props 갱신을 실행했다. 과제마다 새 마운트의 이름 붙은 동작 검사 5개, 방식당 40개다. 실제 브라우저 레이아웃·모든 입력·스크린리더·보안·서버 검증은 아니다.
- **의미와 3축:** 생성자와 다른 새 독립 AI 검토자 A/B가 익명 응답·원문 또는 과제·확정 조건·사전 사실만 읽었다. 방식 이름·생성 지침·자동 점수·서로의 평가를 숨겼다. 두 첫 판정과 정확한 인용 근거를 보존했다. 사람의 정답 판정이 아니고, 문장·코드의 특징으로 방식이 짐작될 가능성은 남는다.

처음 고정한 계획의 단일 조사자 검토는 생성 시작 후, 조사자가 응답을 열람하기 전에 두 독립 검토로 확장했다. [절차 변경 기록](review_extension.json)을 별도로 남겼고 생성 전에 고정한 의미·스타일 기준은 바꾸지 않았다. 생성 이후 집계 스크립트는 이 고정 기준의 개별 횟수를 계산하며 새로운 종합 점수나 순위를 만들지 않는다.

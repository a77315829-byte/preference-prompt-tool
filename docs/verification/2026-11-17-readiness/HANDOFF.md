# 최종 제출·인계 체크리스트

11/17 확인 기준. 다음 주 운영·시연 준비를 앞당긴 기록이며 교수자·수업의 공식 제출 요구사항을 대신하지 않는다. 현재 PR을 최종 제출 버전으로 태그하거나 자동 병합하지 않는다.

## 지금 준비한 것

- [x] 제품 목표와 범위: 요약의 명시 조건을 재사용 지침으로 만들고 조건 준수와 내용 보존을 구분한다. 코딩 두 기능은 유지한다.
- [x] 요약 조건 확인→명시적 저장→새 작업 복사 경로 및 두 코딩 경로의 자동 시연.
- [x] 합성 자료·별도 DB·모델 호출 없는 로컬 실행 절차.
- [x] 백업·무결성 확인·새 저장소 복원 도구와 손상·덮어쓰기 거절 검사.
- [x] 실제 서버 재시작/복원 후 저장 지침·인수인계·첨부 및 계정 접근 경계 확인.
- [x] CI에서 생략한 데이터 의존 검사 3개를 최신 코드로 로컬 재실행.
- [x] 기존 분석·설계 원고와 UC/WBS에 이번 수정·운영 검증 연결.
- [x] 5~7분 시연 순서와 실패 시 대응, 합성 화면 캡처 준비.

## 최종 제출 전에 남는 것

| 일 | 담당·완료 증거 |
|---|---|
| 팀원 PC에서 실행 및 팀원 참석 리허설 | 팀원이 [DEMO.md](DEMO.md)를 따라 실행하고 일시·참석자·발견 사항 기록. 자동 브라우저 검사를 사람 리허설로 대신 기록하지 않기 |
| 공식 제출 요구사항·마감 확인 | 담당 교수/수업 공지의 필수 파일 형식·영상 길이·마감·제출 위치를 팀이 확인 |
| 최종 보고서·발표·영상 | 확정 범위/결과/동률/한계 반영, 실제 화면 녹화, 보고서·슬라이드의 코드 기준 버전 일치 |
| 분석·설계서/WBS 최종 PDF·Excel 발행 | 현재 개정 원고를 최종 제출 판본으로 발행하고 기존 v1.2/v3.3 원본 보존 |
| 확정 커밋·검사·버전 인계 | PR 검토와 필요한 병합 후 실제 제출 커밋에서 검사 성공 확인, 그때 제출 태그·파일 목록·해시 고정 |

사람의 사용성·선호 추정 정확도·시간 절감·팀 채택 효과, 공개 서비스 운영, 새 유료 모델 실험은 이번 필수 완료 조건으로 추가하지 않는다. 필요하다면 별도 과제로 계획한다.

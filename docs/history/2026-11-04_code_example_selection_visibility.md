# 2026-11-04 코드 예시로 선호 고르기 진입 개선

사용자가 선호 선택의 코드가 사라졌는지 물어 확인했다. 기존 코드 A/B 비교는 유지돼 있었지만 최근 GEPA 화면 확인 과정에서 직접 설정 카드 경로를 사용해 보이지 않았다. 코드를 보며 선택하는 진입점을 선호 선택 화면 자체에 명시했다.

- 상단에 `코드 예시로 고르기`(추천)와 `설정만 빠르게 고르기`를 추가했다. 환경 설정으로 돌아가지 않고 방법을 전환할 수 있다.
- 확인 화면에서도 `코드 예시를 보며 다시 고르기`로 비교를 연다. 직접 선택한 설정을 비교 확인으로 자동 처리하지 않는다.
- 예시 조회에 실패하거나 비교를 취소하면 기존 설정을 유지한다. 취소하면 원래 화면으로 돌아가며, 이미 생성한 프롬프트도 보존한다. 네 항목의 비교를 완료할 때만 새 비교 선택과 출처를 적용한다.
- 언어 기본 문법/프레임워크 전용 예시와 제한 안내를 접힌 영역 밖에 표시했다. 현재 새 흐름의 전용 비교 예시는 FastAPI·Spring Boot이며 그 외 목록 언어는 기본 문법 예시다. 기존 React 비교는 별도 진입점으로 유지한다. GEPA 환경별 과제 연결을 새 프레임워크 비교 예시 준비 완료로 해석하지 않는다.
- 직접 입력한 미지원 언어에는 코드 비교를 비활성화하고 설정 카드로 안내한다.

프론트 검사 86개와 Vite 빌드가 통과했다. 새 검사는 직접 선택→코드 비교의 실패/취소 보존, 기존 결과에서 재비교 취소 후 생성문 유지, 완료 후 출처와 선택 반영, 언어 기본 예시 범위와 미지원 직접 입력을 확인한다. 서버·저장 스키마·모델 호출 경로·기존 보관 항목은 변경하지 않았다.

로컬 예시 계정에서 TypeScript/NestJS의 설정 카드→코드 비교 전환과 두 코드·선택 버튼·기본 문법 안내를 확인했다. 유료 AI 호출이나 보관함 저장은 하지 않았다. 화면 증거는 Git에 넣지 않는 `data/coding-example-selection.jpg`다.

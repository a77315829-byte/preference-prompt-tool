# 내 선호 보관함

`codex/summary-coding-no-aws`에 개인 계정용 요약·코딩 프롬프트 보관함을 추가했다.
기존 비교 엔진·팀 선호 합산·업무 작업 공간은 수정하지 않았다.

## 기능

- 비교 결과에서 현재 보고 있는 프롬프트에 이름을 붙여 저장한다.
- 로그인이 필요하면 같은 화면에서 진행한다. 제목·비교 결과를 유지하며 로그인 후 명시적으로 저장한다.
- 상단 메뉴·첫 화면·내 계정에서 보관함을 열 수 있다.
- 요약(한국어·영어)·코딩 분류, 이름·설명 검색, 본문 수정·삭제와 직접 추가를 제공한다.
- 새 원문·개발 요청을 넣으면 저장된 지침과 합친 요청문을 복사할 수 있다. 예시 자료도 제공한다.
- 실제 생성 모드에서는 서버가 정한 모델로 실행한다. 생성한 코드를 자동 실행하지 않는다.
- 실행 결과에는 저장 버전을 표시하며 입력·지침이 바뀌면 이전 결과로 구분한다.
- 보관함 화면은 필요할 때 불러와 첫 로드의 번들 증가를 줄였다.

## 저장·실행

- SQLite migration 6에 `personal_prompts`를 추가했다. 로그인 사용자 소유 조건으로 모든 읽기·수정·삭제·실행을 제한한다.
- 계정당 100개, 제목 100자, 설명 1,000자, 지침 20,000자, 새 작업 12,000자까지다.
- 저장 버전을 확인해 오래된 수정·삭제·실행 요청은 409로 거부한다. 저장 실패 시 편집 내용을 유지한다.
- 보관함에는 이름·분류·설명·지침만 저장한다. 작업 원문이나 새 실행 결과를 보관함에 자동 저장하지 않는다.
- 실제 실행은 기존 `generate_with_prompt`의 캐시·시간 제한·출력 상한을 재사용한다.
- 실행 시도 상한은 서버 하루 60회·사용자 하루 20회이며 환경변수로 설정한다. 실패도 차감된다.
- 탈퇴하면 외래키 CASCADE로 개인 보관함이 삭제된다. 팀으로 자동 공유하지 않는다.

## 검증

- Python: 852 passed, 21 deselected. 유료 API 검사 16개와 기존 Windows 코딩 평가기 실행 경로 오류 5개를 제외했다.
- 새 보관함의 저장·수정·삭제·재시작, 계정 격리, 탈퇴, 입력 상한, 오래된 버전, 실행 모드·사용량·서버 모델 선택과 오류 응답을 검사했다.
- Node: 35 passed. 실제 React 화면에서 결과 저장·수정·새 작업 복사·실행·재방문,
  로그인 중 입력 유지, 빈 보관함, 저장 실패 보존, 삭제 확인·로그아웃과 기존 팀 참여 흐름을 확인했다.
- 프론트 프로덕션 빌드·Python 구문·diff 공백 검사 통과. 새 의존성은 추가하지 않았다.
- 유료 모델 호출·원격 배포·실제 사용자 만족도 평가는 하지 않았다.

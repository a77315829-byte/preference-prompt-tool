# 2026-11-04 README의 전체 기능 화면 보완

기존 README의 화면이 코딩 지침에 치우쳐 문서 요약과 팀 협업·업무 기능을 시각적으로 설명하지 못한 점을 보완했다.

- 문서 요약을 첫 기능 소개로 배치하고 한국어 회의록의 A/B 선택과 생성한 지침을 실제 로컬 화면으로 추가했다.
- 보관함의 대표 화면은 한국어 요약·개인/팀 조합·코딩 지침이 함께 보이는 목록으로 변경했다.
- 회의록의 개인 선호와 팀 기준 비교, 항목별 작업용 조합, 실제 팀 초대 링크를 추가했다.
- 팀 업무 템플릿, 요청문 구조 점검, 반복 업무 지침 작성 시작, 인수인계 참고 파일의 열기·다운로드를 각각 설명과 함께 넣었다.
- GEPA 실행 안내와 받은 답변의 직접 확인도 상세 화면에 추가했다.
- 기존 7장에 12장을 더해 총 19장이다. 이미지별 설명과 출처는 `docs/screenshots/current/capture-info.json`에 기록했다.

격리된 예시 계정과 예시 자료만 사용했다. 요약은 규칙 기반 데모이며, 답변 직접 확인에는 시연용이라고 표시한 준비 답변을 입력했다.
유료 GEPA·AI 수정안·모델 시험 경로는 실행하지 않았다. 캡처를 위해 앱 소스나 결과를 합성하지 않았다.
고정 메뉴가 부분 캡처를 가리는 경우 해당 캡처에서만 메뉴를 숨겼다.

이미지 내용을 시각적으로 확인하고 README의 이미지 19개 및 로컬 문서 링크가 존재하는지 검사했다.
이번 변경은 README·화면 자료·캡처 출처 기록만 대상으로 하며 기존 애플리케이션 코드와 실험 수치는 변경하지 않았다.

# 비교에서 고른 항목만 이전 방식으로 되돌려 새 항목 저장

저장된 조합의 비교 표에서 바뀐 항목을 체크하고, 고른 것만 직전 값·출처로
되돌린 새 지침을 만든다. 선택하지 않은 항목은 현재 값을 유지한다.
현재 조합과 이전 작업용을 덮어쓰지 않고 다른 이름의 별도 항목으로 저장한다.

- `saved_preference_restore.py`는 서버가 저장한 변경 전 기록과 현재 출처에서
  선택을 계산하고 기존 재조합 생성기를 사용한다. 현재 팀이나 과거 항목의
  실시간 조회는 필요하지 않으며 비교 원본을 삭제해도 동작한다.
- `restore-preview`·`restore-save`는 소유권·버전을 확인하고, 바뀐 항목의
  비어 있지 않은 중복 없는 선택만 받는다. 복원 결과·선택에 연결된 미리 보기
  스냅샷을 확인하고 같은 이름을 거부한다. 임의 본문·출처·추가 선택은 사용하지 않는다.
- `SavedRemixComparison`은 바뀐 행에 체크 칸을 제공한다. 같은 행, 기록 없는
  비교, 본문·종류가 수정된 비교, 편집 화면과 저장 전 비교에는 복원 동작을 넣지 않는다.
- `RestoreComparedPreferencePanel`은 복원 개수, 결과 항목·출처·전체 지침,
  다른 이름 저장과 새 항목 열기를 제공한다. 선택을 바꾸면 미리 보기를
  초기화하고, 이름·설명과 현재 작업 입력은 유지한다.
- 새 결과의 변경 전 기록은 복원 직전 현재 조합이다. 기존 기록을 갱신하지 않는다.

검증: 관련 Python 검사 41개, 프론트 검사 49개와 빌드 통과.
코딩·한국어/영어 요약, 두 지침 언어, 일부/전체 복원, 미정 값, 무효·중복 선택,
미리 보기 불일치, 권한, 원본 무변경과 이전 항목 삭제 후 처리를 확인했다.
실제 분리된 예시 화면에서 코드 구성만 복원·새로 저장·다시 열었으며,
1개 변경·2개 같음으로 타입과 스타일이 유지됨을 확인했다.
새 의존성·DB 스키마 변경·유료 모델 호출·원격 배포는 없다.

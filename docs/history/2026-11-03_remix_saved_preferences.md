# 저장한 작업용에서 선택을 다시 바꿔 새 항목으로 저장

출처가 기록된 작업용 지침을 열면 기존 선택을 표시하고 저장 당시 개인·팀 값 중
따를 쪽을 바꿀 수 있다. 같은 기준은 유지하며 새 조합 미리 보기를 확인한 뒤
기존 항목과 다른 이름으로 저장한다. 현재 작업 입력과 기존 저장본은 유지한다.

- `saved_preference_remix.py`는 기존 파이프라인과 분리되어 저장한 출처만으로
  조합한다. 현재 팀이나 원래 개인 항목을 조회하지 않는다.
- 저장 기록과 본문·종류가 일치하고 현재 틀로 원문을 재현할 수 있는지 확인한다.
  선택 출처가 없거나 본문·종류가 바뀐 경우는 새 팀 비교를 안내한다.
- `remix-preview`는 소유권·버전·선택을 검증한다. `remix-save`는 미리 보기
  스냅샷을 확인한 뒤 서버에서 다시 조립한 본문과 출처로 새 항목을 만든다.
  클라이언트의 임의 본문·출처·종류는 사용하지 않는다. 원본과 같은 이름도 거부한다.
- 최초 개인·팀 출처는 유지하고, 직전 작업용의 이름·버전을 재조합 이력으로 남긴다.
  새 기록은 언어도 저장한다. 이전 출처 기록은 원문 전체 재현으로 언어를 확인한다.
- 화면은 선택 변경 시 미리 보기를 무효화하고 실패 시 이름·설명을 유지한다.
  저장 후 새 항목 열기·재사용과 변경된 출처 표시를 제공한다.

검증: 관련 Python 검사 34개, 프론트 검사 45개와 빌드 통과.
코딩·영어 요약·한국어 요약, 한국어·영어 지침 문구, 이전 언어 미기록 출처,
원본 삭제 후 재조합, 원본 무변경, 잘못된 선택·오래된 미리 보기·권한 거부를 확인했다.
실제 예시 화면에서도 파일 구성·타입 선택을 바꿔 다른 이름으로 저장하고 다시 열었다.
새 라이브러리·DB 스키마 변경·유료 모델 호출·원격 배포는 없다.

# 조합한 작업용 지침을 새 항목으로 저장

이번 작업용으로 조합한 지침에 이름·선택 설명을 붙여 개인 보관함에 별도
항목으로 저장한다. 저장 후 현재 작업을 유지하며 새 항목은 목록에 즉시
추가된다. 저장한 항목을 열어 다음 작업에 사용·복사·실행할 수 있다.

- `POST /api/preferences/{id}/save-task`는 원본 소유권·버전, 팀 분류·스냅샷,
  항목별 선택과 작업용 스냅샷을 검증한 뒤 서버에서 다시 조립하여 생성한다.
  클라이언트가 임의로 보낸 prompt·domainKey·task·output은 저장하지 않는다.
- 기존 `PersonalPromptStore.create`를 사용하므로 원본 개인 지침과 팀 기준을
  갱신하지 않으며, 이름·설명·본문 크기와 계정당 100개 제한을 유지한다.
- 저장본은 이후 팀이 바뀌어도 팀에 연결하지 않고 독립적으로 재사용한다.
  기본 생성문과 작업용 출처 안내 문구의 정확한 전체 일치만 축 확인에 허용한다.
  수정·최적화한 본문은 계속 추측하지 않는다.
- `SaveTaskPreferencePanel`은 이름·설명, 새 항목 저장, 중복 클릭 방지,
  저장 실패 시 입력 유지, 저장한 작업용 열기를 제공한다.

검증: 관련 Python 검사 23개와 프론트 검사 43개, 프론트 빌드 통과.
실제 브라우저에서 예시 개인 지침과 팀 기준을 조합해 새 항목 저장,
다시 열기, 새 작업 입력과 요청문 복사를 확인했다.
화면 확인용 데이터는 `data/task-library-preview.db`로 기존 `app.db`와 분리했고
API는 `PPT_LIVE=0`으로 실행했다. 실제 유료 모델 호출은 수행하지 않았다.
새 의존성·DB 스키마 변경·원격 배포는 없다.

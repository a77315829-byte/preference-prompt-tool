# 2026-10-06 외부 리뷰 대응 (7e64f7d 기준)

리뷰가 짚은 다섯 가지를 코드로 재현해 모두 맞는 지적임을 확인했고, 넷은 고쳤다. 남은
하나(2)는 실험 해석의 정정이다.

## 정정: GEPA 시드 조건 실험은 탐색 결과다

`experiments/gepa_seed_conditions.py` 를 커밋하면서(1397f4e) "어떤 조건도 ROUGE-L 에서
조립본을 이기지 못했고, 이것이 GEPA 를 제품 단계가 아니라 검증 도구로 두는 근거"라고 적었다.
**근거로 쓰기에는 조건이 맞지 않는다.** 이 결과로 GEPA 를 앱에서 빼거나 남기는 결정을 하지 않는다.

| | 이 실험 | 실제 앱 |
|---|---|---|
| 후보 생성 모델 | gpt-4.1-mini | gpt-4o-mini |
| 성찰 모델 | gpt-4.1-mini | gpt-5.6-luna (`service.REFLECTION_MODEL`) |
| 시작 프롬프트 | `build_seed_prompt` (짧은 실험용) | `service.final_prompt` (역할·규칙·출력 형식) |
| 표본 | 5문서, 부호검정 전부 p=1.0 | - |

- "일부 선호만 준" 조건(partial)은 상대 확신도로 축을 고르는데, 5문서 중 3문서에서 두 축을
  모두 남겨 조립본과 **같은 시드**였다. 그 조건은 사실상 2문서만 시험했다.
- "중립 프롬프트" 조건도 채점은 선택 이력으로 만든 평가 함수로 한다. 비교 선택을 건너뛰는
  경로를 시험한 것이 아니라, 같은 선호 정보를 시드 대신 평가 함수로만 준 경우다.

실제 앱 조건(모델·시드)으로 다시 재야 GEPA 의 추가 효과를 말할 수 있다. 유료 재실험은 아직
하지 않았다.

## 고친 것

1. **GEPA 후보 평가가 캐시를 거치지 않았다** (절대 규칙 2 위반). `DefaultAdapter` 에 모델
   이름을 문자열로 주면 litellm 을 직접 부른다. `service.cached_task_model` 이 생성 캐시
   (`engine.generator.generate_with_prompt`)를 거치는 함수를 넘긴다 - 앱 최적화와 위 실험
   스크립트 둘 다. 대가는 속도다: 함수로 넘기면 GEPA 는 평가를 동시 10개가 아니라 하나씩
   부른다. 빈 응답은 캐시하지 않고 빈 문자열(0점)로 넘겨 최적화가 계속되게 했다. 성찰 모델
   호출은 여전히 캐시하지 않는다 (횟수가 적고 입력 형식이 달라 따로 판단할 일).
2. (위 정정)
3. **팀 1:1 의견 충돌이 "아무도 선호를 정하지 않음"으로 표시됐다.** 10-06 의 "정하지 못한 축"
   수정(f5fc542)이 만든 회귀다. 두 사람의 확신이 대칭이면 합친 효용이 정확히 같아져 "신호
   없음"에 걸렸다. 이제 `undecided` 는 표가 하나도 없을 때만이고, 반반으로 갈린 축은
   `tied` 로 남는다. 둘 다 팀 프롬프트에서는 빠지지만 화면 문구가 다르다.
   (보완: 이 수정은 값이 2개인 축에서만 맞았다. 값이 3개인 축은
   `2026-10-06_team_tie_three_values.md`.)
4. **부호검정이 한쪽 꼬리만 셌다.** 5승 0패는 0.0625 인데 0승 5패는 1.0 이었다. 저장소 공통
   함수(`experiments/result_statistics.sign_test_p`)를 쓴다. 저장된 결과의 p 값(모두 1.0)은
   바뀌지 않음을 테스트로 대조했다.
5. **거부될 최적화가 횟수를 먼저 깎았다.** 전부 "비슷해요"인 세션은 최적화가 거부되는데,
   API 는 그 확인 전에 하루·세션 횟수를 차감했다. `service.check_optimizable` 를 차감 앞에서
   부른다.

함께: `scripts/summarize_feedback.py --json` 이 한국어 윈도우(PYTHONUTF8 없음)에서 cp949 로
나와 테스트 3개가 실패했다. `--json` 일 때만 표준 출력을 UTF-8 로 고정한다 - 사람용 표 출력은
예전과 바이트까지 같아야 한다는 기존 테스트(`test_default_output_unchanged`)가 있어서다.

회귀 테스트: `tests/test_review_fixes.py`, `tests/test_summarize_feedback_cli.py` 의
`test_json_is_utf8_without_utf8_mode`.

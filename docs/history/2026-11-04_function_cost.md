# 2026-11-04 기능 저하 원인 (4차 사전등록) — 확증 미실행

- 설계·규칙: `docs/function_cost_preregistration.md` (생성 전 커밋 3d76b6d). (a) 없음 / (b) 기본 조립본 / (s) 선호 절을 뺀 틀.
- 과제 고르기에서 범위(0.4~0.85) 안 과제가 2개뿐이라 규칙대로 확증을 돌리지 않았다. 원인 질문(Q1~Q3)은 판정하지 않는다.
- 후보 다섯은 너무 쉬웠고(합친 통과율 1.0), 둘은 시나리오가 요청의 글자를 엄격히 요구해 (a)(b) 모두 실패했다.
- 배운 것: 요청 문구만으로 중간 난이도를 미리 만들기 어렵다. 다음에 이 질문을 잰다면 (1) 후보를 15~20개로 늘려 고르기를
  하거나, (2) 이미 결과를 본 2차 과제처럼 (b) 저하가 보였던 과제 유형을 새로 써서 쓰되 "결과를 보고 고른 유형"이라고 밝혀야 한다.
- 비용: 생성 40회(입력 27,291 / 출력 23,558 토큰, 공급자 보고). 확증 몫 90회는 쓰지 않았다.

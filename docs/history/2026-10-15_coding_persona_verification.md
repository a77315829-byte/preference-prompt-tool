# 코딩 AI 저장 결과 독립 검증 — 2026-10-15

## 범위

저장된 실제 AI 응답을 오프라인으로 검사했다. 추가 API 호출은 0회이며,
이번 검사로 추가 모델 비용은 발생하지 않았다. 가상 사용자는 정해진 선호에
따라 선택하는 자동 검증용 설정이다. 실제 사람의 만족도 평가나 모델 학습이 아니다.

- 입력: `data/coding_persona_live_2026-10-15.json`
- 결과: `data/coding_persona_evaluation_2026-10-15.json`
- 위 두 파일은 로컬 검증 자료이며 Git에 포함하지 않는다.

## 결과

| 검사 | 결과 |
| --- | --- |
| 카운터 A/B | 6쌍, 12개 후보 모두 타입·빌드·검사한 동작 통과 |
| 선택 결과의 선호 복원 | 서로 반대 취향인 가상 사용자 2개 모두 목표와 일치 |

따라서 전체 품질 판정은 **미통과**다. 기능 동작이 통과했다고 모든 스타일
요구까지 만족했다고 보고하지 않는다.

## 발견한 한계

`역할 분리 / 테마 / 타입 명시` 취향으로 생성된 FAQ의
`export default function FAQ()`에 반환 타입이 빠져 있다.
기존 스타일 검사는 타입 표기 개수에 기반하므로 이 문제를 놓쳤다.
이번에는 기존 검사와 별도로 공개 함수의 반환 타입 누락 검사를 추가했다.
저장된 AI 원문을 수정해서 통과한 것으로 처리하지 않았다.

FAQ 동작은 처음 모두 닫힘, 각 질문 열기·닫기, 여러 질문 동시 열기,
다른 질문에 영향을 주지 않는 닫기, 다시 모두 닫기를 확인했다.
카운터는 초기값·증가·초기화 동작을 확인했다.
이는 해당 시나리오의 동등성이지 모든 입력에서의 기능 동등성 증명은 아니다.
CSS를 실제 화면에 렌더링한 시각 비교는 포함하지 않았다.
추가한 반환 타입 검사는 일반적인 exported function 선언을 대상으로 하는
보조 규칙이며 모든 TypeScript 구문을 포괄하는 분석기는 아니다.

## 재실행

생성 코드의 안전성을 먼저 검토한 경우에만 아래 명령을 실행한다.
검사는 임시 폴더에서 생성 코드를 컴파일하고 실행한다.

```bash
.venv/bin/python -m benchmarks.coding_ai_quality.evaluate_persona_poc data/coding_persona_live_2026-10-15.json data/coding_persona_evaluation_2026-10-15.json --reviewed
.venv/bin/pytest -q tests/test_coding_persona_evaluation.py tests/test_coding_ai_quality_stage4.py tests/test_coding_domain.py tests/test_coding_ai_quality_benchmark.py
```

평가 명령의 정상 종료는 검사가 실행됐다는 뜻이다. 품질 통과 여부는 결과
JSON의 `passed`를 확인한다. 이번 값은 `false`다.

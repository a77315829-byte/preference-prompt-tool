# 멘토링 발표 자료와 작은 개발팀 README

브랜치: `codex/summary-coding-no-aws`.

사용자가 다운로드 폴더의 ‘제목을 입력해주세요. (1).pptx’를 지정해 현재 제품 소개, 실제 화면,
WBS·R&R을 요청했다. 후속 답변으로 master 병합 대신 브랜치를 보관하고 PR만 생성하도록 확정했다.

- 원본을 유지하고 브라우저 창 디자인·색상·글꼴을 재사용했다. 가로 화면이 잘리지 않도록 사진 설명 레이아웃의 창 너비를 조정했다.
- 본문 16장, 상세 화면 부록 5장으로 구성했다. 목적·대상 사용자, 개인/팀 기준 연결, 기존/추가 기능, 검증 계획을 구분한다.
- 로컬 예시 DB와 무료 데모에서 18개 화면을 새로 캡처했다. 실제 사용자 자료·API 키·비밀번호는 포함하지 않았다.
  조합과 복원은 미리보기만 하고 기존 지침을 수정하지 않았다. 유료 모델을 호출하지 않았다.
- PPT 발표자 노트와 별도 `발표대본.md`에 약 5분 대본을 넣었다. WBS·R&R은 편집 가능한 표다.
- WBS는 11월 4일~12월 1일의 4주 계획안이다. R&R은 팀장(본인), 이현우, 김홍경, 조현우, 주성준의 배정 제안이다.
  사용자 실제 이름을 추측하지 않았으며 역할·모집·일정은 팀 합의 전 계획이고 수행 실적이 아님을 표시했다.
- `README_SMALL_TEAM.md`에 제품 목적·대상·현재 기능·제한·실행·인수인계·WBS·R&R·검증 범위를 별도로 작성했다.
  루트 README에서 새 문서와 발표 자료를 연결하고 기존 연구 기록을 별도 절로 구분했다.

검증:

- 최종 PPT 21장·21개 발표자 노트, 원본 크기 20 × 11.25인치, 편집 가능한 표 4개를 확인했다.
- 원본 템플릿을 기준으로 PPTX 형식 검사 통과. 최종 패키지·글꼴 정책·제목 맞춤·필수 표 검사 및 Artifact Tool 재열기 통과.
  템플릿에서 가져온 16장의 주황색 배경 그래픽이 슬라이드 바깥으로 이어지는 경고 1건은 의도한 원본 디자인이다.
- 모든 슬라이드를 렌더링해 확인하고 빈 목록 표기와 캡처 위치를 수정했다. 최종 파일을 다시 열어 전체 렌더링을 확인했다.
  PowerPoint에서 직접 열었다고 주장하지 않는다. 원본과 최종 파일의 제목·본문 안내 문구 잔여 항목도 확인했다.
- `tests/test_reported_results.py`, `tests/test_handoffs.py`, `tests/test_handoff_files.py`: 51개 통과.
- 프론트 전체 검사: 64개 통과. 이번 변경은 문서·발표 자료이며 기능 코드는 수정하지 않았다.
- 새 의존성을 추가하지 않았다. 원본 다운로드 파일, 기존 `docs/interim_report/`와 `output/`은 변경·커밋하지 않았다.

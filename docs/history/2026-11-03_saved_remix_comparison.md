# 새 조합과 직전 작업용의 변경 전·후 비교

재조합 미리 보기와 저장한 새 항목을 열 때 직전 작업용의 항목과 비교한다.
전체·변경·같음 개수를 보여 주고 기본은 바뀐 항목만 강조한다.
전체 항목 보기를 선택하면 유지한 방식과 출처까지 나란히 확인할 수 있다.

- `remix_saved_prompt`는 `remixed_from`에 직전 작업용의 이름·버전과
  항목별 라벨·값·출처를 보관한다. 이전 변경 이력을 중첩하지 않고
  바로 전 항목만 복사하므로 재조합 횟수에 따라 기록 크기가 늘지 않는다.
- 기존 작업용을 수정·삭제해도 비교할 수 있다. 클라이언트가 보낸 임의의
  비교 기록은 사용하지 않고 기존 서버 재조합·저장 경로가 생성한다.
- `compareRemixAxes`는 축 이름으로 대응하고 값 변경·출처만 변경·같음·기록
  확인 필요를 구분한다. 미정(빈 값)과 기록 없음은 별도로 처리한다.
- `SavedRemixComparison`은 변경 전·후 이름, 방식, 출처를 표시한다.
  본문·종류 수정 시 비교가 현재 내용과 다를 수 있음을 안내한다.
  비교 기록이 없는 이전 저장본을 추측해 채우지 않는다.
- 좁은 화면에서도 항목·변경 전·변경 후 세 열이 함께 보이도록 줄바꿈한다.

관련 Python 검사 34개, 프론트 검사 48개와 빌드 통과.
프론트 통합 검사에서 미리 보기·저장 후 비교, 변경 없음, 전체/변경 항목 전환,
수정 중 안내와 이전 기록 미존재 처리를 확인했다. 실제 예시 브라우저에서도
2개 변경·1개 같음, 전·후 출처와 전체 항목 보기를 확인했다.
기존 작업용·개인 지침·팀 기준은 유지한다. 새 라이브러리·DB 스키마 변경·유료
모델 호출·원격 배포는 없다.

# 개인·팀 기준 비교와 선택 재사용

`codex/summary-coding-no-aws`의 내 선호 보관함에 같은 분류의 팀 기준을 비교하고
새 작업에 개인용·팀용을 골라 쓰는 흐름을 추가했다.

## 동작

- 내 팀·최근 본 팀을 고르거나 초대 링크·코드를 붙여 넣어 비교한다.
- 기본 생성문 전체가 정확히 일치할 때만 개인 선호 축을 확인한다. 기존 보관함에도 별도 이전 없이 적용된다.
- 직접 추가·수정하거나 최적화한 지침은 선호 값을 임의 추정하지 않고 본문 차이를 펼쳐 보여 준다.
- 항목별 개인·팀 값, 같음·다름·미정, 팀 합의 필요·임시 기준을 표시한다.
- 저장 이름은 비교하지 않는다. 본문 비교용으로만 개인·팀 대상 설명을 맞춘다.
  문구 차이가 곧 의미 차이라는 자동 판정이나 유사도 점수는 제공하지 않는다.
- 실제 복사·실행에는 비교용 문구가 아닌 선택한 개인·팀 지침 원문을 사용한다.
- 기준을 바꿔도 입력 작업은 유지되며, 개인·팀 원본은 변경하지 않고 팀에 자동 참여하지 않는다.
- 팀 확인 실패 시 이전 팀 지침을 선택할 수 없게 한다. 새 팀을 확인하면 개인용으로 돌아가 다시 선택하게 한다.
- AI 실행 전에 현재 팀 기준의 지침·합의 상태·인원·문구 언어 스냅샷을 다시 확인한다.
  달라졌으면 409로 중단하며 모델 호출이나 사용량 차감은 하지 않는다.
- 실행 결과의 개인·팀 구분을 표시하고 입력·지침·기준 선택이 달라지면 이전 결과로 표시한다.
- 빈 팀, 다른 종류의 팀, 오래된 개인 버전은 거부한다. 비교는 모델을 호출하지 않는다.

## 검증

- Python 858 passed, 21 deselected. 유료 API 16건과 기존 Windows 평가기 실행 경로 오류 5건 제외.
- Node 39 passed. 기준 차이, 복사에 팀 원문 사용, 개인·팀 전환, 변경된 팀 기준의 재확인,
  비교 실패 후 이전 선택 차단, 입력 보존, 긴 본문의 차이 비교 제한을 포함한다.
- 프로덕션 빌드·Python 구문·diff 공백 검사 통과. 새 의존성과 DB 스키마 변경 없음.
- 기존 엔진·팀 합산·개인 저장 모듈은 변경하지 않았다. 비교 로직은 `preference_comparison.py`로 분리했다.
- 실제 유료 모델 호출, 원격 배포, 사용자 만족도 검증은 수행하지 않았다.

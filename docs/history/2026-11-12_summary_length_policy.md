# 요약 길이 정책과 조건 충돌 처리 v2

2026-11-12 · 주간보고서 v0.6의 다음 주 계획 중 요약 입력·조건 경계 개선.

## 변경한 동작

| 상황 | 이전 | 현재 |
|---|---|---|
| 요약 시작에 12,000자 초과 입력 | 앞부분을 자동으로 잘라 세션 시작 | HTTP 400. 화면은 입력 전체를 남기고 길이·수정 안내, 시작 차단 |
| 조건 확인의 원문 길이 | 서버는 초과 거절, 시작 경로와 불일치 | 두 경로 같은 검사. 공백을 포함한 유니코드 코드 포인트 기준 |
| 요약 초점 300자 초과 | 브라우저 `maxLength`의 UTF-16 기준으로 입력 제한 | 원문과 같은 코드 포인트 기준. 입력 보존·안내 후 확인 차단 |
| 서로 다른 완전한 원문 2문장 + 완전 발췌 + 최소 5문장 | 충돌을 찾지 못하고 지침 생성 | 지침 보류. 분량 축소 또는 재서술을 직접 선택 |
| 고른 3문장 모두 발췌 + 최대 2문장 | 분량 확대·재서술·생략 선택 | 기존 선택 유지. 전체 보존 요청/일부 생략을 결과에 구분 |
| 원문·분량·보존 문장 변경 | 출력 무효화 | 출력·해결 방식 초기화 유지. 서버도 이전 충돌용 선택 거절 |

길이 검사는 앞뒤 공백을 제거하기 **전**에 한다. 허용 범위의 원문은 기존처럼 앞뒤 공백만 정리하고 본문을 자르지 않는다.
한글 음절과 단일 이모지 `🙂`는 각각 1개 코드 포인트지만, 결합 문자·조합형 이모지는 여러 개일 수 있다.
12,000자와 300자는 서비스 입력 한도이며 요약 품질을 보장하는 연구 결과가 아니다.

## 충돌의 범위와 결정

분량은 기존 YAML 기준을 유지한다: 짧게 1~2문장, 보통 3~4문장, 자세히 5문장 이상.
새 v2 지침은 완전 발췌를 서로 다른 완전한 원문 문장의 사용으로 명시하고,
문장 반복·쪼개기·새 내용 생성으로 최소 분량을 맞추지 않도록 한다.

- **상한 충돌**: 고른 원문 문장이 최대 분량보다 많다. 분량만 확대하거나, 재서술만 허용하거나, 일부 생략을 명시적으로 허용한다.
- **하한 충돌**: 발췌 가능한 서로 다른 완전한 문장이 최소 분량보다 적다. 가능한 기존 분량으로만 축소하거나 재서술을 허용한다.
- **완전한 문장 0개**: 분량 축소로 해결됐다고 처리하지 않는다. 원문을 보완하거나 재서술을 선택할 수 있다.
- **해결하지 않은 충돌**: `needs_resolution`, 빈 `prompts`·`task_requests`. 선택을 미리 체크하지 않는다.
- **분량만 조정**: 표현 방식·초점·보존 요청을 유지한다. 보존할 문장과 가용 원문을 모두 담을 수 있는 기존 분량을 고른다.
- **재서술**: 길이를 유지하고 발췌 조건만 완화한다. 압축 가능성·최소 분량 충족·내용 보존이 입증됐다는 뜻이 아니다.

문장 경계는 규칙으로 추정한다. 원문에 줄바꿈·인용·특수 약어가 있으면 사람이 확인해야 한다.
필수 문장 최대 8개는 선택 한도이며 선호 비교 최대 8회와 별개다. 이번에 비교 횟수·조기 종료 기준은 변경하지 않았다.

## 구현 경계와 기존 자료 보존

- `summary_input_policy.py`: 요약 시작과 조건 확인의 공통 입력 정책. 요약 세 도메인에만 적용.
- `summary_contracts_v2.py`, `domains/summary_contract/v2.yaml`: 제품용 조건 확인 v2. API 응답 `version: 2`, 충돌 종류·허용 선택·적용 길이·보존 요청 정책 포함.
- React 기본 요약 시작과 완료 화면: 입력 길이 안내, 초과 입력 보존, 충돌별 선택, 적용 전후 조건과 일부 생략 표시.
- 모델 호출·GEPA 실행·추가 라이브러리·DB 마이그레이션 없음. 조건 확인 내용은 자동 저장하지 않는다.
- 재사용 지침에는 원문·선택 문장을 넣지 않는다. 작업용 함께 복사에만 포함한다. 다른 원문에서는 조건을 다시 확인한다.
- 기본 비교 완료 지침은 기존 경로이며, 이번 조건 확인은 별도 작업용 지침이다. 기존 지침을 충돌 검사까지 통과한 것으로 표시하지 않는다.
- 과거 `summary_contracts.py`, `domains/summary_contract.yaml`, 요약 YAML·검사·벤치마크 결과는 고정한 채 유지한다.
- 코딩의 AI 답변 방식 설정, React 코드 스타일 비교 및 기존 코딩 지침은 유지한다.

## 검증과 해석

[실행 스크립트와 검증 증거](../verification/2026-11-12-summary-policy/)를 함께 보관한다.
신규 검사에는 한글·이모지·공백의 경계값, 문자열 아닌 입력, LIVE 분기 이전 거절,
문장 부족·중복·약어, 충돌별 허용 선택, 선택 이후 원문 변경, 실제 HTTP 및 UI를 포함했다.
기존 요약·코딩 검사를 포함한 전체 회귀와 실제 Chromium 데모 흐름을 실행했다.

유료 모델 API 없이 합성 입력과 기존 로컬 캐시로 **서비스의 정책·동작**을 확인한다.
새 원문에서 모델이 만든 요약의 내용 보존 개선, 수동 지침 대비 우위, 실제 사용자의 편의성은 이번 검사로 주장하지 않는다.
v0.6 보고서와 이전 평가를 소급 수정하지 않는다. 한국어 정량 내용 복원율도 산출하지 않는다.

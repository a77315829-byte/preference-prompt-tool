# 원하는 개발 환경·직접 고른 선호로 코딩 지침 만들기

브랜치: `codex/summary-coding-no-aws`.

코딩 시작 화면에서 언어·프레임워크를 선택하거나 직접 입력하고, 설명·주석·코드 구성·출력 방식과
추가 선호로 지침을 조립한다. 기존 TypeScript/React 비교는 별도 진입 버튼으로 유지하고,
기존 팀 초대·템플릿·보관함에서 시작하는 React 비교도 그대로 둔다.

- `coding_instructions.py`는 선택을 검증하고 지침을 조립하는 별도 모듈이다. 모델 호출과 코드 실행은 없다.
  직접 선택한 선호를 예시 비교에서 추정한 결과로 표현하지 않는다. `engine/`·coding YAML·검사기는 변경하지 않았다.
- `/api/coding-instructions/preview`는 로그인 없이 조립 결과를 확인한다. 저장은 기존 계정별 보관함을 사용한다.
- migration 8은 `personal_prompts.coding_profile_json`을 추가한다. 기존 항목은 NULL이며 본문·버전은 그대로다.
  새 항목은 검증된 설정과 실제 조립 본문이 일치할 때만 설정 스냅샷을 저장한다.
- 목록에는 개발 언어·프레임워크만 요약하고 지침·추가 선호는 상세 조회에 둔다. 소유권과 저장 버전 검사는 기존 경로를 사용한다.
- 설정 변경 시 미리 보기를 비우고 다시 생성해야 저장할 수 있다. 생성·저장 실패 시 입력을 유지한다.
  로그인도 화면 안에서 진행하고 이름·결과를 보존한다. 생성 화면은 필요할 때 불러온다.
- 저장본은 당시 환경·선호를 표시하고, 새 요청을 붙여 복사·재사용한다. 설정으로 다른 지침을 만들 때 원본은 수정하지 않는다.
  본문·종류를 수동 수정하면 원래 설정과 현재 지침이 다를 수 있음을 표시한다.
- 직접 설정 지침에 React 팀 기준을 적용하지 않도록 화면에서 팀 비교를 제공하지 않고 서버에서도 비교·조합·팀용 실행을 거절한다.
  개인용 모델 실행은 기존 명시적 실행 경로를 유지하며 생성 코드를 실행하지 않는다.

검증:

- 관련 Python 검사 100개 통과: 자유 입력, 16개 선호 조합, 잘못된 설정, 미리 보기·저장 무모델 호출,
  소유권, 원본 유지, 수동 수정 후 설정 불일치, 이전 DB migration, React 팀 기준 적용 차단과 개인용 재사용 확인.
- 프론트 검사 58개와 프로덕션 빌드 통과. 직접 입력, 재생성, 저장 실패, 로그인 중 보존,
  보관함 재사용·원본 유지, 기존 React 비교와의 이동을 확인했다.
- 전체 Python 회귀 검사 908개 통과. 실제 모델 호출 16개와 기존 Windows 실행 경로 관련 5개는 제외했다.
  실행: `python -m pytest -m "not api" -k "not holdout_runtime_checks_accept_known_correct_examples and not faq_runtime_checks_reject_an_answer_visible_before_click" -q`.
- 별도 예시 DB의 실제 화면에서 Elixir/Phoenix 직접 입력으로 조립하고, Python/FastAPI 및 단계별 설명·역할 분리로
  새 지침을 저장했다. 보관함에서 저장 당시 설정을 확인하고 새 요청과 함께 복사했다. 기존 React 비교 입력 화면도 확인했다.

새 의존성·유료 모델 호출·원격 배포는 없다. 모든 언어의 코드 정확도·개인 적합성은 검증하지 않았으며
언어별 비교·검사·팀 기준 연결은 후속 범위다.

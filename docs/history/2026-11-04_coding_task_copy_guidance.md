# 2026-11-04 코딩 프롬프트와 이번 작업 함께 복사 안내

- 결과 화면 제목을 `이 프롬프트로 작업 요청하기`로 변경했다.
- 위에서 만든 답변 방식과 아래에 입력하는 이번 작업을 합쳐 복사하는 영역임을 설명한다.
- 작업 입력 → 답변 방식과 함께 복사 → AI 대화창에 붙여넣기의 세 단계를 안내한다.
- 입력칸에는 할 일만 적도록 돕고, 버튼은 `내 답변 방식 + 이번 작업 복사`로 표시한다. 입력 도움말을 접근성 설명으로 연결했다.
- 클립보드 조합·AI 실행 위치·보관함 저장 범위는 유지한다. 이번 작업은 저장하지 않는다.
- 기존 코딩 흐름 테스트 12개와 프론트 빌드를 통과했다. 테스트는 새 버튼 문구에 맞춰 수정했다.

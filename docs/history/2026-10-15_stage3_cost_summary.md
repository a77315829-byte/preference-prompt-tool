# 3단계: 코딩 AI 사용량·비용 정리

확인일: 2026-10-15 / 브랜치: `codex/coding-ai-upgrade`

이번 단계에서는 기존 로컬 실행 기록만 집계했습니다. 추가 유료 호출은 하지 않았습니다.

## 결론

- 아래 원본 기록 5개에는 호출 시도 21회가 있습니다. 사용량이 확인된 18회의 입력은 23,493토큰, 출력은 16,487토큰입니다.
- 확인된 토큰의 표준 단가 기준 계산 금액은 **$0.0144156 (약 $0.01442)**입니다.
- 사용량이 없는 실패 시도 3회와 이 집계 밖의 과거 실행 비용은 알 수 없습니다. 이 금액은 프로젝트 전체 지출이나 실제 청구액이 아닙니다.
- 제공업체 사용 내역·청구서와 대조하지 않았습니다. 실제 과금 모델, 서비스 수수료, 할인 등에 따라 청구액은 달라질 수 있습니다.

## 단가와 계산 방법

OpenAI 공식 모델 문서에서 확인한 표준 단가입니다. 단위는 100만 토큰당 USD입니다.

| 모델 | 입력 | 캐시 입력 | 출력 |
| --- | ---: | ---: | ---: |
| GPT-6 Luna | $0.10 | $0.01 | $0.50 |
| GPT-6.1 Sol | $2.00 | $0.10 | $10.00 |

출처: [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol).

계산: `((입력 - 캐시 입력) × 입력 단가 + 캐시 입력 × 캐시 단가 + 출력 × 출력 단가) / 1,000,000`.
이번에 사용량이 확인된 기록의 캐시 입력은 모두 0입니다. 금액 계산에는 Decimal을 사용했습니다. 환율 환산은 하지 않았습니다.

## 중복과 해석 주의

- `coding_persona_repaired_2026-10-15.json`은 기존 12회 호출 기록을 복사한 파생 결과이므로 다시 더하지 않았습니다. 평가 결과 파일도 신규 생성 호출로 세지 않았습니다.
- 과거 벤치마크 중 토큰이 없는 기록은 생성 코드 길이로 토큰이나 비용을 추정하지 않았습니다. 누적 호출 횟수가 있는 파일끼리 단순 합산하지 않았습니다.
- 이번 가상 사용자 PoC 원본 12회와 성공한 수정 호출 1회의 확인분 합계는 **$0.0089663**입니다. 실패한 수정 시도 1회의 비용은 별도 미확인입니다.
- 성공한 대표 A/B 생성 2회의 확인분은 $0.0007040이지만, 모든 기능 입력이나 전체 사용자 세션의 고정 가격은 아닙니다. 질문 횟수, 코드 길이, 수정과 상위 모델 전환에 따라 달라집니다.
- 가상 사용자 검증은 정해진 취향을 자동으로 선택한 PoC입니다. 실제 사람 만족도 평가나 모델 학습이 아닙니다.

## 발표에 사용할 설명

“실제 AI 실행 기록에서 사용량이 확인된 18회 호출은 입력 약 2만 3천 토큰, 출력 약 1만 6천 토큰을 사용했습니다. 공식 표준 단가로 계산하면 약 0.0144달러입니다. 다만 사용량을 받지 못한 실패 호출과 과거 미기록 실행은 제외했으며, 제공업체 청구서로 확인한 금액은 아닙니다. 가상 사용자 검증과 실제 사람의 만족도 평가는 구분하고 있습니다.”

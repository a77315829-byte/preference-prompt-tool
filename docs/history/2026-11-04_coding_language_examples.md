# 언어별 코딩 예시 비교

사용자가 기존 React처럼 다른 언어에서도 예시를 고르며 작성 선호를 찾을 수 있도록 확장했다.

- `coding_examples.py`에 14개 언어의 작은 주문 합계 함수 예시를 별도로 둔다. 설명, 주석, 함수 구성, 전체 코드/변경 부분을 한 항목씩 비교한다. 모델 호출·생성 코드 실행은 하지 않는다.
- 프레임워크는 최종 지침에 반영한다. 비교 자체는 언어 기본 문법 예시이며 프레임워크 전용 구현이나 코드 품질 검증을 주장하지 않는다.
- 네 항목을 직접 선택하거나 판단을 보류할 수 있다. 보류는 기존 설정을 유지한다. 이전 항목 수정과 전체 비교 취소를 제공한다.
- 지침 생성과 보관함 저장에 개발 환경·선택·예시 버전을 함께 남긴다. 저장본에서 항목별 비교 선택/보류를 확인하고 새 지침에 다시 사용할 수 있다. 원본은 덮어쓰지 않는다.
- 환경이나 선호를 수동으로 바꾸면 비교 출처를 초기화한다. 지침 본문을 수정한 저장본에서는 과거 설정이라는 기존 안내를 유지한다.
- 기존 React 예시 비교·팀 기준은 유지한다. 새 비교 결과는 개인용이며 React 팀 기준과 자동 조합하지 않는다. 목록에 없는 언어는 기존 직접 설정을 사용한다.
- 새 의존성, DB migration, 엔진 변경은 없다. 연구용 선택 추정·최적화 결과와 별도 기능이다.

검증: 관련 Python 테스트 58개(새 예시·비교 출처, 저장/재사용/계정 격리, 기존 지침·보관함·엔진 규칙), 프론트 전체 66개, Vite 빌드 통과. 최초 API 테스트는 샌드박스의 localhost 소켓 연결 제한(WinError 10013)으로 실패해 허용된 실행 환경에서 재검사했다. Python 예시의 계산 동작을 검사했으며 다른 언어의 실행·컴파일이나 프레임워크 호환성을 검증한 것은 아니다.

실제 로컬 브라우저에서도 Python/FastAPI와 Java/Spring Boot로 네 항목을 선택했다. 별도 미리보기 DB의 예시 계정에 Java 비교 지침을 새로 저장하고 다시 열어 선택 출처와 판단 보류가 유지됨을 확인했다. 기존 보관함과 운영 DB는 덮어쓰지 않았다.
